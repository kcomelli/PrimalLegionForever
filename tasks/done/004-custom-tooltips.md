# 004 – Custom tooltips

**Status:** done (2026-10-05)

## Description
Replace the browser default tooltips (`title`) of the countdown and the Discord link with styled tooltips
matching the page design.

## Acceptance criteria
- [x] Style fits the design: navy + gold border, cream text, arrow, short fade + slide
- [x] Countdown tooltip left (wide screens) or top (≤ 900px)
- [x] Discord tooltip below the logo
- [x] Touch devices: tap the countdown to show its tooltip
- [x] Keyboard accessible (focus shows tooltip), reduced-motion respected
