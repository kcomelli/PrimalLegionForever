# Color scheme

Extracted (color quantization) from `media/PLLogoDraft7.png` (guild logo) and
`media/guild_symbol_9_512x512_transparent.png` (guild symbol).
Defined as CSS custom properties in `website/style.css` (`:root`).

| Variable | Hex | Source / use |
|---|---|---|
| `--gold-light` | `#fae5a0` | Logo highlights |
| `--gold` | `#f0c972` | Logo main gold – primary accent |
| `--gold-mid` | `#c69547` | Logo mid gold |
| `--gold-dark` | `#9e6926` | Logo shaded gold |
| `--bronze` | `#764a15` | Logo shadows |
| `--cream` | `#fdf7cd` | "FOREVER" lettering – text color |
| `--brown-dark` | `#1a0900` | Logo outline |
| `--royal-blue` | `#002355` | Symbol banner |
| `--navy` | `#011a41` | Symbol banner shade |
| `--navy-deep` | `#00102d` | Page fallback background, `theme-color` |

Character: gold/cream on deep royal blue (Alliance-like heraldry).
